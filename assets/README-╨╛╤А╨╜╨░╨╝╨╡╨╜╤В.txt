Игра «Восстанови последовательность» — свои картинки по регионам
-----------------------------------------------------------------

Для Татарстана уже подготовлены реальные плитки (нарезаны из
вашего референса): ornament-tatar-1.png ... ornament-tatar-5.png

Чтобы добавить свой узор для другого региона — нужно 5 квадратных
картинок в правильном порядке (том, в котором элементы должны
встать при сборке):

  assets/ornament-karelia-1.png  ... assets/ornament-karelia-5.png
  assets/ornament-kalmykia-1.png ... assets/ornament-kalmykia-5.png
  assets/ornament-yakutia-1.png  ... assets/ornament-yakutia-5.png

Как только для региона появятся все 5 файлов — игра начнёт их
использовать автоматически, ничего в коде менять не нужно.

Пока файлов для региона нет — используются татарские плитки
с лёгким сдвигом оттенка (просто чтобы экран не был пустым).
Это временная заглушка, не финальный узор региона.

Рекомендуемый размер каждой плитки: квадрат, от 300×300px,
формат PNG (можно с прозрачным фоном, можно без).
