Как добавить настоящие иллюстрации маскотов вместо SVG-заглушек
-----------------------------------------------------------------

У маскота несколько поз (состояний) — под каждую своя картинка.
Имя файла: assets/mascot-<регион>-<поза>.png

Регионы:     tatar / karelia / kalmykia / yakutia / neutral
             (neutral — нейтральный маскот для главной и «Как это работает?»)

Позы:
  plain    — обычный, стоит на кружке-тени       (карточка культуры)
  glasses  — в очках                              («Не знаешь язык? Это нормально»)
  book     — с книгой                              (подсказка в квизе)
  cap      — в шапочке-конфедератке                (экран результата)
  flex     — с гантелями                           (главная и «Как это работает?»)
  cook     — готовит (с половником)                (оба экрана рецепта)
  shapes   — с летающими фигурками                 (игра «Восстанови последовательность»)

Например:
  assets/mascot-tatar-plain.png
  assets/mascot-tatar-cap.png
  assets/mascot-karelia-cook.png
  assets/mascot-neutral-flex.png

Как получить эти файлы из Figma:
  1. Выделите нужную позу маскота нужного региона.
  2. Правая панель → Export → PNG, масштаб 2x (или 3x).
  3. Экспортируйте и назовите файл точно как выше.
  4. Положите в эту папку.

Как только файл появится — он подставится сам, на нужном экране,
без правок кода. Пока файла нет — рисуется лёгкая SVG-заглушка
в градиенте цветов региона (взят из вашего Figma-экспорта).
